# 服务器文件管理

在机器行点击**文件夹图标**，或在机器详情点击**文件**。默认打开 `/data/home`，可以直接输入绝对路径、返回上级、进入目录或预览文本。多个账号可以访问同一机器时，可切换操作账号。

## 上传到指定目录

1. 点击**上传文件**，填写**目标目录**，例如 `/data/home/workspace/assets`。
2. 选择一个或多个文件。最终路径是目标目录加原文件名；列表会显示每个文件的完整目标路径。
3. 需要时勾选**自动创建不存在的目录**，然后点击**开始上传**。
4. 文件按顺序上传，逐个显示进度。进度到 100% 后仍会等待服务器确认保存；出现“上传完成”才表示收到了有效的成功响应。
5. 目标已存在时先停止该文件，显示**确认覆盖**，点击后才发送覆盖请求。其他文件仍继续上传。上传失败、取消或响应丢失不会自动重传。

单个文件最多 **95 MiB**，以适应 Cloudflare 100 MB 的请求体限制。文件通过面板流式转发，没有 JSON/base64 膨胀；API Key 不发给浏览器。官方上传接口支持更大的文件，但本面板没有开启直传或分片续传。

上传时保持页面打开。可以取消当前上传并停止后续文件；取消与服务器完成保存可能同时发生，因此取消或网络中断后请先刷新目标目录核对，再决定是否重传。切换账号会清空本地上传列表；上传进行中禁止切换账号、修改路径和关闭文件窗口。

官方接口先接收临时文件，再替换目标，正常中断不会留下半个目标文件。**同名检查与上传不是原子操作**：平台当前没有条件写入参数，检查后另一客户端仍可能创建或改动同一路径。覆盖也可能跟随目标符号链接。多人或多工具同时写同一目录时，应使用唯一文件名，核对目标后再覆盖。

## 其他操作

- **浏览和预览**：目录最多返回 5000 项，文本最多预览 256 KiB，截断会有提示。二进制文件请下载后查看。符号链接可打开，路径栏显示平台解析后的实际路径。
- **下载**：通过浏览器下载完整文件，保留二进制字节；远端 HTML、SVG 等作为附件下载，文本预览只显示原文。
- **新建目录**：在当前目录新建一层目录。同名目标或权限不足会报错。
- **重命名**：修改同一目录下的名称，不覆盖已有文件或目录。
- **删除**：输入完整路径确认。删除目录包含子目录和文件；删除符号链接只移除链接本身。不提供回收站，也不允许删除或重命名根目录。

路径必须为绝对路径，最长 4096 字节，不接受 `.`、`..` 或控制字符。新文件名最长 255 字节，支持中文、空格及普通标点。含控制字符的已有文件可显示，但不提供面板操作。

文件管理需要 API Key 的 **`machines:write`** 权限。平台目录读取和预览可能使用 root 权限，而上传、下载和修改使用机器登录用户权限，因此能看到某个文件并不保证可以修改或下载它。空闲自动暂停的机器可能在文件访问时由平台恢复；其他未运行状态请先在面板启动或恢复。

## 实现和验证

面板继续使用现有登录与 CSRF 校验。目录与预览调用官方 `GET /v1/machines/{id}/files`；下载调用 `/files/content`；上传调用 `PUT /files`，限制大小并校验返回的字节数和 SHA-256 格式。SHA-256 为上游返回的保存结果，浏览器不额外读取整个文件计算校验值。

新建、重命名、删除通过官方 `/exec` 执行固定的 GNU `mkdir`、`mv`、`rm` 参数列表，文件名作为独立参数发送，无 shell 字符串拼接、无 sudo。重命名使用 `--no-clobber --no-target-directory --verbose`，并识别“同名跳过”的情况；删除不跨文件系统，完整路径确认不能替代文件系统的原子条件删除。执行失败或超时后保留错误并刷新目录，不自动重复命令。

上传单独接受 `application/octet-stream`；其他 API 继续限制 JSON 请求为 8 KiB。流式上传同时检查声明长度、实际字节数和中断，不将整个上传文件缓存在 Worker 内存。下载仅返回允许的附件响应头，不转发上游 Cookie 或凭据。

无需新增 D1 表、环境变量或安装服务器守护进程。新建、改名、删除要求机器可使用 GNU coreutils。演示模式仅在当前页面内存模拟文件，不读写真实服务器。

验证入口：`npm test`、`node tools/browser-check.mjs`、`npm run build` 和 `npm run worker:check`。测试包含本地 workerd 的真实流式上传下载，以及浏览器原生 HTTP 上传进度、中断、覆盖、权限和会话过期。真实 InstaBox 与 Cloudflare 部署链路需上线后验收。
